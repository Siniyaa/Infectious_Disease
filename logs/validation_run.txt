HOW TO REPRODUCE THIS LOG. The analysis functions need the F translations, which the deposited manifests
do NOT contain - they carry metadata and calls only. You must first obtain the sequences (GenBank by the
frozen accession list, GISAID by EPI_ISL export) and run the align stage to produce tr_A_F.fasta and
tr_B_F.fasta. Then build-cohort regenerates analysis_set.pkl and prededuplication_set.pkl, and:
    python pipeline.py stats       --gisaid-meta gisaid.tsv
    python pipeline.py sensitivity --gisaid-meta gisaid.tsv
    python pipeline.py trend       --gisaid-meta gisaid.tsv
    python pipeline.py clesrovimab --gisaid-meta gisaid.tsv
produce the sections below. The present log was generated by calling the same functions directly on the
already-built analysis set.

SCOPE. The cohort-assembly stages (fetch-genbank, sort, align) and the phylogenetic stage are NOT
exercised here. `pipeline.py phylo` prints the exact phylogenetic commands, including which alignment is
passed to TreeTime and the fact that no explicit rooting step was applied. The functions below produce
every number in the manuscript's Results except the acquisition counts and branch support, which come from
the deposited trees under phylogenetics/.
