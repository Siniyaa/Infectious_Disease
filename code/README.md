# Analysis workflow

`pipeline.py` is the workflow. It replaces the earlier prose description (PIPELINE.md), which
described the analysis but could not be executed and is no longer distributed.

Run `python pipeline.py --help` for stages. `python pipeline.py phylo` prints the exact
phylogenetic commands, which were run once interactively and are not wrapped in a function.

`../logs/validation_run.txt` records the output of running the analysis functions against the
deposited analysis set.
